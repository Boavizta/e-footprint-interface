Modeling

How a modeling comes to be and changes in the interface, told by the code that does it. Each narrative below is one flow, walked in the order one test crosses it: the cause the user sets off, then every step the request takes through the views, the use cases and the domain, down to what is saved. A step is a sentence written at its own line, with the values the test saw there.

A dotted link opens VS Code at the line. Right-click it for the diff against main or, on a test, to debug that case.
