Plan for review · 13 October 2026 · Interface-owned

Simplified-input save lock

Specification · Replaces the prior cancellation plan.

The current checkout is the path base. No library or server change is proposed.

1. One Simplified-input field save

The existing save entry validates an edit and triggers the field form's HTMX request. Add one attribute to that form. HTMX gathers its values before disabling the selected controls, so the initiating value is still sent. The selector reaches both resident Simplified-input workspaces.

model_builder/templates/model_builder/simplified_inputs/editor.html · Proposed attribute on the existing form

hx-disabled-elt="button, [data-simplified-workspace] input, [data-simplified-workspace] select, [data-simplified-workspace] textarea"

HTMX removes those temporary disabled attributes when the request ends. Replace the current workspace guard with the small button-state helper from main, extending its original-disabled selector to the native Simplified-input controls. This restores genuine constraint-disabled fields without re-disabling server-rendered replacements. Field edits then own Saving/Saved/Not saved and capture accepted snapshots after controls recover, using their own HTMX completion events. Keep the existing server-rejection restoration.

2. Remove the broad guard

Delete the control map, selector inventory, seven interaction-capture listeners and global workspace mutation lifecycle. Return card-order saving and diagram deletion to their local fetch lifecycles. The browser no longer promises global write serialization or a canceled-edit retry path.

Keep completion behavior with its owner: bookmarks already handle their response; Configure exits follow their own form's HTMX outcome; provenance no longer skips focusout for a global busy flag; and Results cleanup keeps a local wait for any response that can still update its target. Remove these modules' now-unused shared-event or busy-flag branches rather than moving the global bus.

3. Reads and export

The existing HTMX button disabling may briefly make reads unavailable; no read-specific re-enable code remains. The selector above disables the two-model Export toggle with every other button. The two-model menu links and single-model link are left alone and may download saved state during a field save. Remove the obsolete global-busy short-circuit from the existing export listener but keep its dirty-Configure check. No export-specific busy state is added. A direct link reads the saved repository state at request time, which may be the old value or the just-persisted edit; it never resumes a deferred action.

Delivery and verification

First replace the broad guard and connect the field form's native lock; adapt local lifecycle listeners in the same patch so no save status is stranded. Then remove unused cross-module hooks and reconcile the rendering, workspace and original Simplified-input documents and the export spec's busy and global-lock wording at implementation time.
