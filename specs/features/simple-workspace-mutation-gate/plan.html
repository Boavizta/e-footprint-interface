Simplified-input save lock

Specification · Run A implementation guide.

The scoped save and export changes followed the approved plan. Run A also fixed a pre-existing accordion-state defect found during E2E close-out; see the implementation decision below. No library or server change was needed.

Implementation decisions

[IMPL-DECISION-01] Preserve accordion transition state in OOB refreshes — APPLIED

1. One Simplified-input field save

Implemented as planned. The save entry validates an edit and triggers the field form's HTMX request. The form's native disabled selector captures the submitted value before disabling buttons and the input, select and textarea controls inside both resident Simplified-input workspaces. The browser regression checks the submitted request and both workspaces.

model_builder/templates/model_builder/simplified_inputs/editor.html · Implemented selector

hx-disabled-elt="button, [data-simplified-workspace] input, [data-simplified-workspace] select, [data-simplified-workspace] textarea"

HTMX removes its temporary disabled attributes when the request ends. The small disabled-state helper restores genuine prerequisite-disabled controls that remain connected and leaves OOB replacements with their server-rendered constraints. Field edits own Saving/Saved/Not saved feedback and accepted snapshots. Their request handler waits for the matching settle event when an OOB swap is due, while transport failures release status without a swap. The existing server-rejection restoration remains.

2. Remove the broad guard

Implemented as planned. The global workspace mutation lifecycle, its interaction-capture handlers and shared mutation signals are removed. The remaining native disabled-state handler restores prerequisite-disabled controls; it does not serialize workspace writes. Card-order saving and diagram deletion retain their local fetch lifecycles. The browser no longer promises global write serialization or a canceled-edit retry path.

Completion behavior remains with its owner: bookmarks handle their responses; Configure exits follow their form's request outcome and settlement; provenance changes reach the local field-save handler; and Results cleanup tracks recomputation-bearing HTMX requests that can refresh Results from outside its panel. On close, the local wait keeps response targets attached until requests and swaps finish, then reapplies the closed layout.

[IMPL-DECISION-01] — APPLIED

After the user supplied a full E2E failure during close-out, Run A fixed a pre-existing defect in restoreAccordionStateInFragment(). The linked source-metadata resubmission scenario timed out because an OOB card refresh closed the accordion and hid its edit button. The original snapshot treated only the Bootstrap show class as open. During an opening transition Bootstrap temporarily removes it; the accordion's collapsing state and its toggle's aria-expanded destination already reveal that the intended state is open. The helper now preserves that destination when the OOB beforeSwap handler replaces the card; a closing transition remains closed.

This small DOM-state read preserves the existing OOB refresh and fast side-panel save path without adding a wait, reload, global guard or persisted state. The deterministic opening/closing Jest regression and the existing source-metadata resubmission E2E case cover the correction.

3. Reads and export

Implemented as planned. During a field save, the disabled selector makes the Results button and other buttons temporarily unavailable as well. two-model Export toggle unavailable. The two-model menu links and single-model link keep their native destinations and can download saved repository state during a field save. The export listener only blocks dirty Configure drafts; it has no global-busy check. Downloads read whichever value has reached persistence when the request runs, never the unsaved browser field, and settlement does not replay an activation.

Delivery and verification

Implemented as planned. Run A replaced the broad guard, connected the form's native lock and moved save completion to local lifecycle handlers. The published guidance was reconciled in the rendering, workspace and persistence pages, the prior Simplified-input specification and its review guide, the export specification and review guide, plus testing guidance and the changelog.
