# Current-operation projection v1 — 2026-09-15

This first version models e-footprint-interface operation from September 2025 through December 2027. The five JSON
files are alternative adoption scenarios and must not be added together.

The application allocation is 4 vCPU and 2,926 MB process-visible RAM. Pending provider-specific hardware data, its
environmental characteristics are 4/24 of a generic 24-core host: 100 kgCO₂e manufacturing, 50 W maximum power and
8.33 W idle power. This proportional allocation is a low-confidence hypothesis.

| Scenario | Modeled usage occurrences | Total footprint | Minimum–maximum application instances |
|---|---:|---:|---:|
| Low | 6,875 | 100.723 kgCO₂e | 1–1 |
| Medium | 11,375 | 124.448 kgCO₂e | 1–1 |
| High | 42,125 | 285.601 kgCO₂e | 1–1 |
| Team | 391,625 | 922.385 kgCO₂e | 1–1 |
| Agent | 3,826,625 | 1,294.684 kgCO₂e | 1–5 |

The reported totals are useful for checking and exploring the model, not yet article conclusions. Their main
limitations are visible in the input comments:

- production browser latency is used as a calibration for server duration pending correlated production logs;
- average CPU use, request/response bytes, and the physical allocation behind the Clever Cloud container are
  hypotheses;
- PostgreSQL and Redis capacity are not yet inventoried separately;
- the shared-complex-model journey uses a 1.5× complexity multiplier rather than a dedicated benchmark;
- user devices dominate the human journeys because session durations are informed hypotheses rather than observed
  analytics;
- S6 excludes the calling agents' inference and execution footprint pending model, token, region, and host evidence.

The server remains at one instance through the team scenario: even 50,000 monthly occurrences do not produce one full
average concurrent request after the workload is spread across regional work hours. The agent scenario reaches five
instances at its hourly peak. The full-RAM-per-request assumption forces another instance whenever modeled average
concurrency crosses an integer; it does not invent within-hour bursts that are absent from the traffic series.

All five generated files passed both the e-footprint JSON round trip and the interface's
`SystemImportService.import_system` materialization boundary with 19 usage patterns: eighteen journey/geography slices
and one synthetic keep-alive pattern.
